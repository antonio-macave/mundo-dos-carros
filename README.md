# Mundo dos Carros - Aplicativo Android

O **Mundo dos Carros** é um aplicativo Android que permite aos usuários consultar informações detalhadas sobre marcas, modelos e preços de carros disponíveis no mercado brasileiro. Os dados são alimentados directamente pela **FIPE**, garantindo informações precisas e atualizadas sobre o valor dos veículos.

## Funcionalidades

- **Consulta de Carros**: Acesso a uma lista completa de marcas e modelos de carros no Brasil.
- **Preço Actualizado**: Os preços dos veículos são obtidos directamente da tabela FIPE, uma das fontes mais confiáveis de preços no mercado brasileiro.
- **Filtros de Pesquisa**: Filtros para buscar carros por marca, modelo, ano, preço, entre outros critérios.
- **Design Intuitivo**: Usando o Material Design, o aplicativo conta com uma interface amigável e fácil de navegar, proporcionando uma experiência fluida no Android.
- **Atualizações Constantes**: O aplicativo recebe actualizações regulares com as informações mais recentes da FIPE.

## Tecnologias Utilizadas

- **Plataforma**: Android
- **Frontend**: Kotlin & Jetpack Compose
- **API de Preços**: FIPE (tabela oficial de preços de veículos no Brasil)
- **Design**: Material Design

## Como Usar

1. **Instalar o APK**: 
   Baixe o arquivo APK e instale no seu dispositivo Android.

2. **Iniciar o Aplicativo**: 
   Após a instalação, abra o aplicativo e comece a pesquisar por carros!
